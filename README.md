# EasyCrawl downloads

EasyCrawl turns a credits spreadsheet into a scrolling end-credits movie.

Download the latest version from [Releases](https://github.com/RJ2320/easycrawl-downloads/releases/latest).

- **Windows:** run the EasyCrawl Setup executable. It creates a Start menu shortcut, with an optional desktop shortcut.
- **Mac (Apple silicon):** open the disk image and drag EasyCrawl into Applications.

Python and FFmpeg are included. Project fonts must be installed separately.
The application checks for updates at launch; installing a newer download updates the app.

Windows and macOS may show a security warning because these builds are not yet code-signed/notarized.

This repository contains public downloads only. Development source and production project material are private.
